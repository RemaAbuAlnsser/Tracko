## 📋 نظرة عامة

**Tracko** هو نظام متكامل لإدارة التدريب الميداني للطلاب، يربط بين الجامعات والشركات والطلاب والمدربين في منصة واحدة. يوفر النظام أدوات ذكية لمطابقة الطلاب مع فرص التدريب المناسبة باستخدام الذكاء الاصطناعي، بالإضافة إلى إدارة شاملة لخطط التدريب والتقارير والتواصل.

### ✨ المميزات الرئيسية

- 🤖 **مطابقة ذكية بالذكاء الاصطناعي**: نظام AI لمطابقة الطلاب مع فرص التدريب المناسبة
- 💬 **نظام محادثة فوري**: دردشة مباشرة بين جميع الأطراف باستخدام Supabase
- 📊 **إدارة خطط التدريب**: متابعة المهام والتقارير الأسبوعية والنهائية
- 🔔 **نظام إشعارات متقدم**: إشعارات فورية لجميع الأحداث المهمة
- 📱 **تطبيق موبايل**: تطبيق React Native للوصول من الهاتف المحمول
- 🎥 **مكالمات فيديو**: نظام مكالمات فيديو مدمج باستخدام ZegoCloud
- 📄 **تحليل السيرة الذاتية**: رفع وتحليل السير الذاتية بالذكاء الاصطناعي
- 📈 **لوحات تحكم تفاعلية**: إحصائيات ورسوم بيانية لجميع المستخدمين

## 🏗️ البنية التقنية

### التقنيات المستخدمة

#### Backend (الخادم)
- **Node.js** + **Express.js** - إطار عمل الخادم
- **MySQL** - قاعدة البيانات الرئيسية
- **MongoDB** - قاعدة بيانات للبيانات غير المنظمة
- **Socket.io** - الاتصال الفوري
- **Bcrypt** - تشفير كلمات المرور
- **Multer** - رفع الملفات
- **Node-cron** - جدولة المهام التلقائية

#### Frontend Web (الواجهة الويب)
- **React.js** - مكتبة بناء الواجهات
- **React Router** - التنقل بين الصفحات
- **Recharts** - الرسوم البيانية
- **Supabase** - قاعدة بيانات الدردشة الفورية
- **ZegoCloud** - مكالمات الفيديو
- **Socket.io Client** - الاتصال الفوري

#### Frontend Mobile (تطبيق الموبايل)
- **React Native** - إطار عمل التطبيقات المحمولة
- **TypeScript** - لغة البرمجة
- **React Native Image Picker** - اختيار الصور والملفات
- **Supabase** - الدردشة الفورية

## 🚀 التثبيت والإعداد

### المتطلبات الأساسية

- **Node.js** (الإصدار 16 أو أحدث)
- **MySQL** (الإصدار 8 أو أحدث)
- **MongoDB** (الإصدار 5 أو أحدث)
- **npm** أو **yarn**

### 1️⃣ إعداد قاعدة البيانات

#### MySQL
```bash
# تسجيل الدخول إلى MySQL
mysql -u root -p

# إنشاء قاعدة البيانات
CREATE DATABASE trackoDB CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

# استيراد المخطط
mysql -u root -p trackoDB < database_schema.sql
```

#### Supabase (للدردشة الفورية)
```bash
# استيراد جداول Supabase
# قم بتنفيذ محتوى ملف SUPABASE_SETUP.sql في لوحة تحكم Supabase
```

### 2️⃣ إعداد الخادم (Backend)

```bash
# الانتقال إلى مجلد Backend
cd backend

# تثبيت التبعيات
npm install

# إنشاء ملف .env
cp .env.example .env

# تعديل ملف .env بالإعدادات الخاصة بك
nano .env
```

#### محتوى ملف `.env`:
```env
# إعدادات قاعدة البيانات MySQL
DB_HOST=localhost
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=trackoDB

# إعدادات MongoDB
MONGODB_URI=mongodb://localhost:27017/tracko

# إعدادات الخادم
PORT=5050
NODE_ENV=development

# مفتاح التشفير
JWT_SECRET=your_secret_key_here
```

### 3️⃣ إعداد الواجهة الويب (Frontend)

```bash
# الانتقال إلى مجلد Frontend
cd frontend

# تثبيت التبعيات
npm install

# إنشاء ملف .env
nano .env
```

#### محتوى ملف `.env`:
```env
REACT_APP_API_URL=http://localhost:5050
REACT_APP_SUPABASE_URL=your_supabase_url
REACT_APP_SUPABASE_ANON_KEY=your_supabase_anon_key
REACT_APP_ZEGO_APP_ID=your_zego_app_id
REACT_APP_ZEGO_SERVER_SECRET=your_zego_server_secret
```

### 4️⃣ إعداد تطبيق الموبايل (React Native)

```bash
# الانتقال إلى مجلد التطبيق
cd xmd

# تثبيت التبعيات
npm install

# للأندرويد
npx react-native run-android

# للـ iOS
npx react-native run-ios
```

## 👥 أنواع المستخدمين

### 1. الطالب (Student)
- **التسجيل والدخول**: إنشاء حساب جديد وتسجيل الدخول
- **الملف الشخصي**: إدارة المعلومات الشخصية والسيرة الذاتية
- **فرص التدريب**: عرض الفرص المطابقة بالذكاء الاصطناعي
- **التقديم**: التقديم على فرص التدريب
- **خطط التدريب**: متابعة المهام والتقارير
- **التقارير**: رفع التقارير الأسبوعية والنهائية
- **الدردشة**: التواصل مع الجامعة والمدرب
- **الإشعارات**: استقبال إشعارات حول التحديثات

### 2. الشركة (Company)
- **إدارة الملف**: تحديث معلومات الشركة والشعار
- **فرص التدريب**: إنشاء وإدارة فرص التدريب
- **المتقدمين**: عرض قائمة المتقدمين وقبول/رفض الطلبات
- **خطط التدريب**: إنشاء خطط تدريبية للطلاب المقبولين
- **المدربين**: تعيين مدربين للإشراف على الطلاب
- **التقارير**: متابعة تقارير الطلاب
- **الإشعارات**: إشعارات عن التقديمات الجديدة

### 3. الجامعة (University)
- **إدارة الطلاب**: عرض ومتابعة جميع الطلاب
- **فرص التدريب**: عرض جميع فرص التدريب المتاحة
- **التقارير**: مراجعة والموافقة على التقارير
- **الدردشة**: التواصل مع الطلاب
- **الإحصائيات**: عرض إحصائيات شاملة
- **طلبات التسجيل**: الموافقة على طلبات الشركات الجديدة

### 4. المدرب (Trainer)
- **الطلاب المعينين**: عرض الطلاب المعينين للإشراف عليهم
- **التدريبات**: متابعة التدريبات المسؤول عنها
- **التقارير**: مراجعة تقارير الطلاب
- **المهام**: متابعة تقدم الطلاب في المهام
- **الدردشة**: التواصل مع الطلاب

### 5. المدير (Admin)
- **إدارة المستخدمين**: عرض وإدارة جميع المستخدمين
- **الشركات**: الموافقة على الشركات الجديدة
- **الجامعات**: إدارة الجامعات المسجلة
- **الإحصائيات**: عرض إحصائيات شاملة للنظام
- **طلبات التسجيل**: مراجعة والموافقة على الطلبات

## 🔌 واجهات برمجة التطبيقات (API)

### المصادقة (Authentication)
```
POST   /api/auth/signup          # تسجيل مستخدم جديد
POST   /api/auth/login           # تسجيل الدخول
POST   /api/auth/logout          # تسجيل الخروج
```

### الطلاب (Students)
```
GET    /api/students/:id                        # معلومات طالب
PUT    /api/students/:id                        # تحديث معلومات طالب
GET    /api/students/:id/applications           # طلبات التدريب
GET    /api/students/university/:universityId   # طلاب جامعة معينة
```

### الشركات (Companies)
```
GET    /api/companies                    # جميع الشركات
GET    /api/companies/:id                # معلومات شركة
PUT    /api/companies/:id                # تحديث معلومات شركة
POST   /api/companies/:id/approve        # الموافقة على شركة
```

### فرص التدريب (Internships)
```
GET    /api/internships                  # جميع الفرص
POST   /api/internships                  # إنشاء فرصة جديدة
GET    /api/internships/:id              # تفاصيل فرصة
PUT    /api/internships/:id              # تحديث فرصة
DELETE /api/internships/:id              # حذف فرصة
GET    /api/internships/company/:id      # فرص شركة معينة
```

### المطابقة بالذكاء الاصطناعي (AI Matching)
```
GET    /api/matching/student/:userId     # فرص مطابقة للطالب
POST   /api/matching/apply               # التقديم على فرصة
```

### التقديمات (Applications)
```
GET    /api/applications/internship/:id  # متقدمين على فرصة
POST   /api/applications/:id/accept      # قبول متقدم
POST   /api/applications/:id/reject      # رفض متقدم
```

### خطط التدريب (Training Plans)
```
GET    /api/plans/student/:id            # خطط طالب
GET    /api/plans/:id                    # تفاصيل خطة
POST   /api/plans                        # إنشاء خطة جديدة
PUT    /api/plans/:id                    # تحديث خطة
```

### التقارير (Reports)
```
GET    /api/weekly-reports/student/:id   # تقارير طالب
POST   /api/weekly-reports               # رفع تقرير أسبوعي
PUT    /api/weekly-reports/:id/approve   # الموافقة على تقرير
GET    /api/final-reports/student/:id    # التقرير النهائي
```

### الإشعارات (Notifications)
```
GET    /api/notifications/user/:userId   # إشعارات مستخدم
PUT    /api/notifications/:id/read       # تعليم كمقروء
POST   /api/notifications                # إنشاء إشعار
```

### رفع الملفات (File Upload)
```
POST   /api/upload/file                  # رفع ملف
POST   /api/upload/cv                    # رفع سيرة ذاتية
```

## 🔔 نظام الإشعارات

### أنواع الإشعارات

1. **إشعارات التقديم**
   - تقديم جديد على فرصة تدريب
   - قبول/رفض التقديم
   - تحديثات حالة التقديم

2. **إشعارات التقارير**
   - موعد تسليم تقرير أسبوعي
   - الموافقة على تقرير
   - طلب تعديل تقرير

3. **إشعارات المهام**
   - مهمة جديدة
   - اقتراب موعد التسليم
   - الموافقة على حل

4. **إشعارات النظام**
   - فرصة تدريب جديدة مطابقة
   - تحديثات الملف الشخصي
   - رسائل جديدة

### المهام المجدولة (Cron Jobs)

- **إشعارات التقارير الأسبوعية**: كل يوم أحد الساعة 9 صباحاً
- **تذكير المهام**: قبل 24 ساعة من الموعد النهائي
- **تنظيف الإشعارات القديمة**: شهرياً
