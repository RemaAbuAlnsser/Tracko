# دليل رفع السيرة الذاتية وتحليل الذكاء الاصطناعي - تطبيق Tracko المحمول

## نظرة عامة

تم إضافة ميزة رفع السيرة الذاتية مع تحليل الذكاء الاصطناعي في التطبيق المحمول، بنفس الطريقة الموجودة في الموقع الإلكتروني. هذه الميزة تتيح للطلاب:

- رفع السيرة الذاتية (PDF, DOC, DOCX)
- تحليل السيرة الذاتية باستخدام الذكاء الاصطناعي
- عرض نتائج التحليل بشكل منظم
- استخدام نفس قاعدة البيانات والباك إند

## الميزات المضافة

### 1. رفع السيرة الذاتية
- **اختيار الملف**: دعم PDF, DOC, DOCX
- **رفع آمن**: رفع مباشر إلى الخادم
- **تتبع التقدم**: مؤشرات تحميل واضحة
- **التحقق من الملفات**: فحص نوع وحجم الملف

### 2. تحليل الذكاء الاصطناعي
- **تحليل المهارات**: استخراج وتصنيف المهارات
- **تحليل الخبرة**: تقدير سنوات الخبرة
- **تحليل التعليم**: استخراج المؤهلات التعليمية
- **تصنيف المهارات**: تجميع المهارات حسب الفئة

### 3. عرض النتائج
- **واجهة منظمة**: عرض النتائج بشكل واضح
- **تصنيف المهارات**: عرض المهارات مجمعة حسب الفئة
- **معلومات شاملة**: خبرة، تعليم، تخصص

## كيفية الاستخدام

### الخطوة 1: الوصول إلى الميزة
1. افتح التطبيق وسجل الدخول
2. انتقل إلى تبويب "Profile"
3. ابحث عن قسم "CV Upload & AI Analysis"

### الخطوة 2: رفع السيرة الذاتية
1. اضغط على "📁 Select CV"
2. اختر ملف السيرة الذاتية من جهازك
3. تأكد من أن الملف بصيغة PDF, DOC, أو DOCX
4. اضغط على "📤 Upload CV"
5. انتظر حتى اكتمال الرفع

### الخطوة 3: تشغيل تحليل الذكاء الاصطناعي
1. بعد رفع السيرة الذاتية، اضغط على "🤖 Run AI Analysis"
2. انتظر حتى اكتمال التحليل (قد يستغرق بضع ثوان)
3. ستظهر النتائج تلقائياً أسفل القسم

### الخطوة 4: مراجعة النتائج
- **المهارات المكتشفة**: قائمة بجميع المهارات المستخرجة
- **تصنيف المهارات**: المهارات مجمعة حسب الفئة (Frontend, Backend, إلخ)
- **الخبرة**: تقدير سنوات الخبرة
- **التعليم**: المؤهلات التعليمية المستخرجة

## التقنيات المستخدمة

import DocumentPicker from 'react-native-document-picker';

### في الباك إند
```javascript
// APIs جديدة
POST /api/upload/cv - رفع ملف السيرة الذاتية
POST /api/cvs - إنشاء سجل السيرة الذاتية
POST /api/cvs/analyze/:userId - تحليل السيرة الذاتية بالذكاء الاصطناعي
GET /api/cvs/student/:userId - جلب بيانات السيرة الذاتية
```

## هيكل قاعدة البيانات

### جدول CVs
```sql
CREATE TABLE CVs (
  id INT AUTO_INCREMENT PRIMARY KEY,
  student_id INT NOT NULL,
  cv_file VARCHAR(255) NOT NULL,
  analysis_data JSON,
  uploaded_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (student_id) REFERENCES Students(id)
);
```

## معالجة الأخطاء

### أخطاء شائعة وحلولها

#### "No CV found. Please upload a CV first."
**السبب**: محاولة تشغيل التحليل بدون رفع سيرة ذاتية
**الحل**: ارفع سيرة ذاتية أولاً

#### "Failed to select CV file"
**السبب**: مشكلة في اختيار الملف أو صيغة غير مدعومة
**الحل**: 
- تأكد من أن الملف بصيغة PDF, DOC, أو DOCX
- تحقق من صلاحيات التطبيق للوصول للملفات

#### "Network error while uploading CV"
**السبب**: مشكلة في الاتصال بالخادم
**الحل**:
- تحقق من اتصال الإنترنت
- تأكد من تشغيل الخادم على البورت 5050

#### "CV uploaded but failed to create database record"
**السبب**: رُفع الملف لكن فشل في إنشاء السجل في قاعدة البيانات
**الحل**: تحقق من اتصال قاعدة البيانات
