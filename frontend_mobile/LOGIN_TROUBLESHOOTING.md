# حل مشاكل تسجيل الدخول في تطبيق Tracko المحمول

## المشكلة
عند إدخال بيانات طالب صحيحة في واجهة تسجيل الدخول، التطبيق يبقى في حالة تحميل ولا ينتقل إلى واجهة الطالب.

## الحلول المحتملة

### 1. التحقق من اتصال الشبكة
- تأكد من أن الخادم يعمل على البورت 5050
- تحقق من الاتصال بالإنترنت أو الشبكة المحلية

### 2. استخدام بيانات اختبار صحيحة
استخدم هذه البيانات للاختبار:
```
البريد الإلكتروني: teststudent@najah.com
كلمة المرور: 123456
```

### 3. فحص سجلات التطبيق (Console Logs)
افتح أدوات المطور في المحاكي وابحث عن الرسائل التي تبدأ بـ 🔐:
- `🔐 Attempting login with:` - يظهر بيانات تسجيل الدخول والرابط المستخدم
- `🔐 Login response status:` - يظهر حالة الاستجابة من الخادم
- `🔐 Login response data:` - يظهر البيانات المرجعة من الخادم
- `🔐 User type detected:` - يظهر نوع المستخدم
- `🔐 Calling onStudentLogin with user data:` - يظهر عند نجاح تسجيل الدخول

### 4. التحقق من عنوان الخادم
- **iOS**: يستخدم `http://localhost:5050`
- **Android**: يستخدم `http://10.0.2.2:5050`

### 5. إنشاء مستخدم جديد للاختبار
يمكنك إنشاء مستخدم جديد باستخدام هذا الأمر:
```bash
curl -X POST "http://localhost:5050/api/auth/create-user" \
  -H "Content-Type: application/json" \
  -d '{"full_name":"اسم الطالب","email":"student@najah.com","password":"123456","user_type":"student"}'
```

### 6. التحقق من حالة الخادم
```bash
# التحقق من أن الخادم يعمل
curl -X GET "http://localhost:5050/api/auth/test"

# اختبار تسجيل الدخول مباشرة
curl -X POST "http://localhost:5050/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email":"teststudent@najah.com","password":"123456"}'
```

## الأخطاء الشائعة وحلولها

### خطأ "Network error"
- تأكد من تشغيل الخادم: `npm start` في مجلد backend
- تحقق من عنوان IP الصحيح للأندرويد

### خطأ "Invalid email or password"
- تأكد من صحة البريد الإلكتروني وكلمة المرور
- تحقق من وجود المستخدم في قاعدة البيانات

### التطبيق يبقى في حالة تحميل
- تحقق من سجلات وحدة التحكم للأخطاء
- تأكد من أن دالة `onStudentLogin` تعمل بشكل صحيح

2. تم إضافة المزيد من سجلات التشخيص
3. تم تحسين معالجة الأخطاء
